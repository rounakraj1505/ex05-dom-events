# Ex 5 - JavaScript: DOM Elements and Events

**Objective:** Create web pages that demonstrate applications of the Document Object Model and events in JavaScript.

## File
- `ex05-dom-events.html` - single self-contained demo (open directly in a browser)

## What it demonstrates
- Finding elements: getElementById, getElementsByTagName, getElementsByClassName, querySelectorAll
- Events: onclick, ondblclick, onmouseover/out, onkeyup, onchange, onkeydown, onload, onresize
- document.addEventListener / window.addEventListener event log panel

## How to run
Download `ex05-dom-events.html` and open it in any browser.
